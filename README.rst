Heriverse Documentation
=======================

This repository contains the documentation for **Heriverse - Heritage Science Metaverse**,
a 3D online platform for the collection, management, and exploration of multimedial content
for Heritage Science.

The documentation is built with `Sphinx <https://www.sphinx-doc.org/>`_ and hosted on
`Read the Docs <https://readthedocs.org/>`_.

Building locally
----------------

.. code-block:: bash

   pip install -r docs/requirements.txt
   cd docs
   sphinx-build -b html . _build/html

The generated HTML will be in ``docs/_build/html/``.
